Section 3

CS Dashboard

The CS Dashboard is the primary tool for customer service agents. It is used to manage client files, post status updates, send emails, log calls, and submit requests to the dispute team.

Daily Workflow

  1. Log into the portal — you will land on the CS Dashboard automatically
  2. Review the client list on the left — unread messages appear with a red dot
  3. Handle any clients with unread messages first
  4. Work through the Call Queue for any urgent callbacks
  5. Process status update requests from the dispute team

Client Search

Type a client name, ID, phone number, or email in the search box on the left panel. Results update automatically. If a client does not appear, try their ID (starts with CPR-) or phone number.

Opening a Client File

Click any client in the list to open their file. The right panel has tabs:

TabWhat It Does
InfoClient details, contact info, package, status
LoginsBureau login credentials (TransUnion, Equifax, Experian)
DisputesDispute log and items being worked
Contact LogAll call and contact history
Status UpdatePost updates visible to the client portal
EmailSend emails directly to the client
ActionsRequest status update, request refund, pause/resume file
CallsRC dialer call log

Posting a Status Update

  1. Open the client file
  2. Click the Status Update tab
  3. Select a status type from the dropdown
  4. Add notes explaining the update
  5. Click Post Update to Client Portal
  6. The client will see this update when they log into their portal

Sending an Email to a Client

  1. Open the client file
  2. Click the Email tab
  3. Type the subject and message body
  4. Click Send + Post to Portal to send the email AND post it to the client portal simultaneously

Requesting a Status Update from Dispute Team

  1. Open the client file
  2. Click the Actions tab
  3. Under "Request Status Update," select the reason
  4. Add notes
  5. Click Send Request
  6. This will appear in the Requests Inbox for the dispute team
🚫 Never do this:

Do not post status updates or send emails for clients that are marked PAUSED, CHARGEBACK, or have a legal hold. Escalate to Jason immediately.

Section 5

Call Queue — Urgent Callbacks

The Call Queue manages urgent callback requests from clients. CS agents are responsible for working through the queue daily.

Daily Process

  1. Go to /call-queue.html
  2. Select your name from the "You are:" dropdown in the top right
  3. Review all pending callback cards
  4. Click 👋 Assign to Me to take ownership of a callback
  5. Call the client using RC (RingCentral)
  6. Add call notes in the card
  7. Click ✅ Mark Called when done

Filters

Use the filters at the top of the page to view callbacks by agent name or date (Today / Yesterday / This Week). This helps each agent focus on their own assigned items.

💡 Always select your name from the dropdown BEFORE clicking Assign to Me. Your name will not appear on the card otherwise.

Section 6

Dispute Center

The Dispute Center is used exclusively by Marcelo Torres and Annabel Curada to manage and file disputes on behalf of clients.

Workflow

  1. Check the Requests Inbox (/requests-inbox.html) for new requests from CS agents
  2. Open the Dispute Center and find the client
  3. Review the client's bureau logins and dispute items
  4. File disputes with the appropriate bureau(s)
  5. Log the dispute in the client's file with date, bureau, and item disputed
  6. Post a status update to the client portal via the CS Dashboard or Status Update Tool
  7. Email the client confirmation of the dispute filed

Status Update Tool

Open the Status Update Tool for a specific client by going to the CS Dashboard, opening their file, clicking the Actions tab, and clicking Open Status Update Tool. The tool opens pre-loaded with that client's file.

⚠️ Important:

Always log disputes in the portal immediately after filing. Do not rely on memory or external notes.

Section 9

Refund & Signature Tracker

Managed exclusively by Queen Jearel Cruz. Used to track all refund requests from intake to payment.

Refund Process

  1. Client requests a refund — CS agent escalates to Queen
  2. Queen opens /refund-tracker.html and clicks New Refund Request
  3. Enter client name, ID, reason, and refund amount (total paid minus $200 admin fee)
  4. Set status to Under Review
  5. Queen reviews the file and calculates the correct refund based on work completed
  6. Tag for Jason's approval — do NOT process until Jason approves
  7. Once Jason approves, process the refund via the original payment method
  8. Update status to Processed with payment confirmation

Refund Policy

  • $200 admin fee is non-refundable in all cases
  • Refund amount = Total paid minus $200
  • If client cannot provide bureau logins, note "Under Review — client declined to provide bureau access"
  • All refunds require Jason's written approval before processing
