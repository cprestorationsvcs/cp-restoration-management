🌐 Step 6 — Upload to Bureau Portals
After filing the dispute in our system, upload the cover letter + FTC report directly to each bureau's online dispute portal. Click each bureau link to open the portal, then follow the steps below.
⚠️ You must be logged in with the CLIENT'S bureau credentials — not a CP Restoration account. Use the login info collected during client onboarding.
🔵 Equifax
Open my.equifax.com ↗
1. Log in with client's Equifax credentials
2. Click Dispute an Error or go to Credit Report → Dispute
3. Select each disputed account and choose the dispute reason
4. Upload the Equifax cover letter + FTC report + supporting docs
5. Submit and save the confirmation number
🔴 Experian
Open Experian Dispute ↗
1. Log in with client's Experian credentials
2. Click Start a New Dispute
3. Select each account to dispute and choose reason
4. Upload the Experian cover letter + FTC report + ID docs
5. Submit and save the confirmation number
🟢 TransUnion
Open TransUnion Dispute ↗
1. Log in with client's TransUnion credentials
2. Go to Disputes → Start a Dispute
3. Select each account and choose the dispute reason
4. Upload the TransUnion cover letter + FTC report + ID
5. Submit and save the confirmation number
